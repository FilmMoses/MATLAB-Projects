# Applied Numerical Analysis & Computational Mathematics Projects

A collection of applied computational mathematics projects implemented in MATLAB for coursework in numerical analysis, focusing on algorithmic implementations, convergence behavior, and error bounds across multi-part mathematical problems.

---

## 📌 Repository Overview

This repository documents three applied computational projects exploring core challenges in numerical approximation, matrix methods, and discrete solvers:

* **Project 1:** Algorithmic formulation and baseline error convergence analysis.
* **Project 2 (Problems 1 & 2):** Numerical linear systems, iterative solvers, or root approximations under varied step-size configurations.
* **Project 3 (Problems 1 & 2):** Advanced discrete numerical approximations, boundary value problems, or differential systems.
